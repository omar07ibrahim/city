# Phase-0 visual evidence contract

This contract governs the three static SVGs embedded in the repository
README. They are generated evidence, not hand-edited illustrations.

## Analytical question and takeaway

The quantitative chart asks: **how prevalent are four operationally relevant,
row-derived quality observations in the frozen city snapshot when they share
the same denominator?**

The supported takeaway is deliberately narrow. Missing admin name is the
largest of the four observations at 316 rows (0.71%); missing population is
307 (0.69%), repeated city/country/admin excess is 301 (0.67%), and repeated
coordinate excess is 136 (0.30%). All use the same 44,691 profiled-row
denominator. Categories can overlap, so their counts must not be added into a
total affected-row count.

Blank capital classification is excluded because blank is an allowed
source-provided semantic state rather than the same kind of missing-data
observation. Exact country-label variants per ISO2 are excluded because that
count describes label relationships, not rows, and therefore has no honest
row denominator.

## Chart family and data sufficiency

| Contract field | Decision |
| --- | --- |
| Canonical family | Comparison & Ranking |
| Concrete form | Sorted horizontal bar chart with direct labels |
| Observation grain | One aggregate observation per bar |
| Visible rows | Four, the complete predeclared comparable set |
| Measure | Observation count; percentage is a direct label |
| Denominator | `quality.metrics.profiled_rows` = 44,691 |
| Scale | Linear absolute-count axis beginning at zero |
| Sparse-data fallback | Not needed: four meaningful categories meet the minimum useful comparison |

Rates use the manifest's integer parts-per-million representation and are
displayed to two decimal places. The chart does not imply severity, causality,
or mutual exclusivity.

## Palette and non-color encoding

The visual family uses a hard two-root cap: restrained blue (`#2563A6`) for
the quantitative marks and implemented pipeline stages, and gold (`#C18A22`)
for source-binding or freshness proof states. Neutrals provide text, grids,
and panels.

Color is never the only carrier of meaning. The bar chart is sorted, every bar
has a category label plus exact count and rate, the architecture diagram is
numbered and connected in reading order, and the CLI result spells out its
exit code and streams.

## Delivery and footprint

The selected delivery surface is standalone static SVG embedded by relative
path in GitHub Markdown:

| Artifact | Footprint | Purpose |
| --- | ---: | --- |
| `docs/visuals/data-quality-observations.svg` | 1200 × 720 | Source-derived comparison chart |
| `docs/visuals/phase-0-workflow.svg` | 1320 × 520 | Implemented audit and freshness architecture |
| `docs/visuals/audit-cli-result.svg` | 1200 × 560 | Actual successful audit-check subprocess result |

The renderer is `python3 -m urbanlens.visuals` and uses only the Python
standard library. SVGs contain no JavaScript, remote assets, remote fonts,
timestamp, machine path, raw city record, or raw city/country/admin label.

## Provenance and freshness

All visuals are bound to:

- dataset: `train.csv`;
- SHA-256:
  `de941def7faca87c0911abb79c3cbd07672887fd486a9b7bea6c48c12ce0cf18`;
- profiled rows: 44,691;
- checked evidence: `artifacts/data_quality/train.quality.json`;
- manifest schema: `urbanlens.data-quality-manifest`, version 2.

Before rendering in memory, the generator actually invokes
`python3 -m urbanlens.audit train.csv` and requires its stdout bytes to equal
the safely captured checked manifest. It then invokes the displayed
checked-manifest command as a real subprocess and records its normalized
stdout, stderr, and exit code. A terminal fresh audit must still match before
any check or write proceeds.

Regenerate and verify with:

```bash
python3 -m urbanlens.visuals --write
python3 -m urbanlens.visuals --check
```

`--check` renders all three SVGs in memory and compares exact bytes. `--write`
stages files relative to one no-follow directory descriptor and atomically
replaces regular-file destinations. Symlink leaves are rejected, and a
concurrent parent-path swap cannot redirect the writes.

## QA contract

Automated checks cover:

- exact source hash, denominator, metric counts, rates, order, and labels;
- fresh-audit mismatch failure before render or write;
- actual CLI command, streams, and exit code;
- deterministic generated bytes and exact checked-file freshness;
- XML well-formedness, fixed dimensions, titles, descriptions, and zero
  baseline;
- absence of raw source labels, secrets, absolute paths, scripts, remote
  assets, and remote fonts;
- no-follow symlink refusal and anchored parent-swap behavior;
- final browser raster inspection at the exported dimensions when a local
  renderer is available.

The current workflow visual is explicitly phase 0. It does not claim a map,
model, API, live population data, or authenticated upstream release receipt.
